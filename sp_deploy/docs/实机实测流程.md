# 新版自瞄实机实测流程与记录表

本文件是现场执行流程，不是已完成的实机成绩报告。仿真准确度、合成标定和伪终端协议测试均不能替代真实相机、云台和发射机构验收。现场记录应保留原始图像、标定板尺寸、配置/模型哈希、实际发射与命中判定视频。

填写日期、操作者、机器人编号、运行电脑系统/CPU、相机型号与镜头、分辨率、焦距/对焦固定状态、相机 VID:PID、电控固件版本、UART 波特率及单位、实测弹速。先确认电控自身的失联停控与发射权限策略，再进行下面各阶段。

当前配置的 UART44：RX 的 roll/pitch/yaw 浮点偏移为 23/19/27，pitch_vel/yaw_vel 在 31/35；单位默认为度与度/秒，四元数保留区不能当真实四元数。TX 为原 SP 44 字节欧拉角布局，控制模式字节 0/1/2，尾字节 0x0D，CRC 保留为零。两轴加速度**不在这个 UART44 发送布局中传输**；电控需自行实现合适的轴控制与限幅。不要把仿真中完整导数前馈等同于电控实际接收的字段。

## 相机内参

1. 固定实战镜头、分辨率和对焦。确认实际相机画面颜色、清晰度和曝光；避免把传输格式或 Bayer 顺序错误当作模型问题。
2. 机器人保持静止，移动/倾斜标定板，拍摄至少 30–50 张，覆盖中心、四角与不同距离，避免几乎相同的图像。
3. 使用 capture 不加 `--imu`；执行独立 `calibrate` 或完整 `deploy`。核对成功检测比例、覆盖范围、训练 RMS 和留出图像 RMS，不删除失败图像后冒称原始数据全部通过。
4. 在未参与拟合的图像上检查畸变矫正与已知物体尺寸。换镜头、重新对焦或改变分辨率后重新标定。

## 相机到云台外参

1. 机器人底盘和标定板固定，相机刚性安装。板应距离适中且在各姿态中完整可见。
2. 明确云台坐标系为前、左、上；相机为右、下、前。核对 IMU yaw/pitch/roll 的正向和 `R_gimbal2imubody`，每次只动一个轴检查符号。
3. 采集 20–40 个不同 yaw/pitch 组合，每个姿态停稳后保存图像和匹配姿态。只绕 yaw 扫描不能完成可靠的三维手眼标定。
4. 旋转中心共点且位置固定时使用 `--fixed-center`；否则通过实测尺寸/正运动学给出每帧 `gimbal_translation_m`，不能默认填零。
5. 核对 `R_camera2gimbal` 是旋转矩阵、`t_camera2gimbal` 单位为米；与实测安装位置比较。再检查固定标定板恢复到世界后的残差，留出姿态也应满足阈值。
6. 实测枪口相对于标定参考原点的前/左/上位移，填写 `muzzle_offset_gimbal_m`，转换弹道的发射原点；手眼不会自动测量枪管方向或编码器零位。
7. 用多个已知位置的装甲板做独立 PnP 检查，记录距离、左右偏差和高度偏差。不要直接使用仿真外参或另一台车 standard3/4 的外参。

## 分阶段验证

| 阶段 | 操作和应观察的结果 | 原始证据 / 判定 |
|---|---|---|
| 观察 | 不传 `--control`，相机、YOLO、Tracker、MPC 运行，但控制/开火为 false | 待实测 |
| 轴与单位 | 静态目标，明确启用跟踪；检查 yaw/pitch 方向、零位和幅度，没有度/弧度错配 | 待实测 |
| 静态跟踪 | 多距离、多高度、多方位目标，检查偏差与稳定性，先不开火 | 待实测 |
| 动态跟踪 | 固定轨迹横移、旋转、遮挡后重现；记录丢失和重新捕获时间 | 待实测 |
| 故障输入 | 相机中断、IMU 失联、拔插串口；验证软件解除控制与电控本机看门狗 | 待实测 |
| 发射 | 由操作者明确允许实际发射，逐项记录发射数、命中数、距离、速度、弹速、光照 | 待实测 |

软件视觉状态期限为 250 ms，最新 IMU 主机接收姿态期限为 200 ms，规划检查是独立线程，避免相机读取阻塞时沿旧目标持续控制。实际停控延迟还取决于串口写入和电控固件，必须用电控日志或轴测量验证。软件退出时会尝试发送解除控制；硬件和串口故障时不能以此代替电控自身的失联保护。

运行器输出 `SP_REAL_DIAG` JSON：视觉处理时间、图像年龄、Tracker 状态、规划、控制/开火与反馈误差和最新姿态接收年龄。反馈使用独立的最新接收四元数，不消费图像时间戳的历史队列；构建副本新增该接口，原 SP 文件保持只读。这里的图像年龄是原驱动主机时间的差值，尚未证明曝光到姿态的真实时延。实际处理间隔超过 100 ms 时原 Tracker 会重置，需记录并评估 CPU 推理和采集负载。

## 准确度与时间测量

每个实机条件预先定义距离、目标运动、光照、弹速和目标类型，独立重复至少 3 次、每次至少 100 发，分别记录发射、可判定命中、不可判定及未完成事件。以弹丸或发射序号去重，报告 Wilson 95% 区间；不要把触发建议数量当作实际发射数，或把误判视频移除后只统计成功样本。
