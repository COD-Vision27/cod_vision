在本机工作区根目录 `/home/kendas/桌面/zimiao` 执行。仿真渲染、物理、ROS2 和新版 SP 自瞄全部运行在 `wuxian@192.168.1.102`；本机负责调度和显示画面。入口同时启动仿真与自瞄，默认使用 standard3 派生配置，运行 120 秒自动结束。场景类型和转速、距离、横移参数读取 `sp_vision_ros/configs/simulator.toml` 的 `[scenario]` 段；初始默认仍为前方 4 米静态目标，详见[运动参数说明](../sp_vision_ros/configs/README.md)。

## 一条命令：本地看到窗口

```bash
python3 tools/sim_view.py
```

自动打开本机浏览器，地址为：

```text
http://127.0.0.1:6080/vnc.html?autoconnect=1&resize=scale&reconnect=0
```

浏览器显示目标机的独立虚拟桌面和 Bevy 窗口。目标机无需有人登录桌面，渲染仍使用目标机 Vulkan / RTX 4060。本机不需要 ROS、Rust 或 NVIDIA 显卡。如果未自动打开浏览器，复制终端打印的地址即可；也可以在 Codex 浏览器中打开该地址。

## 一条命令：目标机屏幕看到窗口

```bash
python3 tools/sim_view.py --view remote
```

目标机需已登录图形桌面。脚本自动查找显示号和会话认证，不需要手写 `DISPLAY=:0`。当前已验证的是 X11 桌面 `:1`；窗口出现在目标机显示器上。如果桌面锁屏，需要在目标机解锁才能看到。没有可访问桌面时会报错，改用本地查看模式即可。

## 直观观察新版自瞄

```bash
# 旋转目标，观察 3 分钟，本地看画面
python3 tools/sim_view.py --scenario spin --seconds 180

# standard4 派生配置，横移目标，本地看画面
python3 tools/sim_view.py --base standard4 --scenario move --seconds 180

# 同样的横移测试，在目标机桌面显示
python3 tools/sim_view.py --view remote --base standard4 --scenario move --seconds 180
```

`--scenario` 支持 `static`、`spin`、`move`。`--profile`（等同 `--base`）选择 [sp_vision_ros/configs](../sp_vision_ros/configs/README.md) 的 `standard3.yaml`、`standard4.yaml` 或调优候选 `standard3_high_rate.yaml`，保留仿真专用相机内外参，不直接把实机 YAML 填给仿真。

```bash
# 调优 agent 的候选参数
python3 tools/sim_view.py --profile standard3_high_rate --scenario spin --seconds 180

# 使用自己编辑的 YAML 和 Bevy TOML；路径相对于工作区根目录
python3 tools/sim_view.py --aim-config sp_vision_ros/configs/my_tuning.yaml --sim-config sp_vision_ros/configs/my_simulator.toml
```

修改配置后重启即可；构建/测试不会覆盖配置。`active-configs.json` 与配置快照随每次正常结束的作业回传，便于确认改动确实被加载。

画面加载后，左下角可看到 `auto-aim=ON`、`total`、`accurate`、`pct`。静态场景能看到枪口调整与连续射击；动态场景能看到目标旋转或横移后云台跟随。`total=0` 时不能据 `pct` 判断命中率。HUD 用于直观观察，正式资格数据以[测试说明](../sp_vision_ros/docs/测试说明.md)中的逐发遥测、样本量及统计门槛为准。画面保留原光照和阴影，较暗不代表未加载。

本地浏览器中先点击画面让键盘输入进入仿真。F3 切换视角，F4 切换调试信息；F2 为原仿真截图操作。演示默认自动启用自瞄，无需按 F5。保持相机第一人称时便于直接观察瞄准效果。

到时自动结束；提前停止请在启动命令的终端按 **Ctrl+C**。仅关闭浏览器标签不会停止远端作业。脚本结束会清理本次仿真、自瞄、独立显示服务和 SSH 隧道；`--view remote` 保留目标机原桌面。

VS Code 的“终端 → 运行任务”也提供“远程：本地查看仿真窗口”和“远程：目标机显示仿真窗口”两个入口。

## 前提与常用参数

当前目标机的程序已构建，图形查看依赖已安装，通常直接运行上述命令即可。如果构建产物缺失，先在本机调度：

```bash
python3 tools/remote_run.py doctor
python3 tools/remote_run.py --env CARGO_NET_OFFLINE=true build
```

可视化入口同步源码并复用目标机现有二进制，**不自动重编译**。修改 C++、Rust 或 ROS 消息后，先运行远程构建再演示；仅切换上述场景/配置不需要构建。模型、几何或算法修改后的正式验收另按测试说明执行。

```bash
# 只打印浏览器地址；适合手动打开或终端没有默认浏览器
python3 tools/sim_view.py --no-open

# 本机 6080 被占用时换端口
python3 tools/sim_view.py --local-port 6081

# 显示全部诊断（完整日志始终保存，无须加此项）
python3 tools/sim_view.py --verbose

python3 tools/sim_view.py --help
```

端口默认遵从 SSH 配置；支持 `--host`、`--user`、`--port`、`--identity`，也支持 `ZIMIAO_REMOTE_HOST` / `ZIMIAO_REMOTE_USER`。免密认证、同步和串行锁沿用 [remote_run](remote-testing.md)。同一远程工作区一次运行一个作业，结束当前测试后再切换场景。

本地查看链路为：本机浏览器 → 本机 `127.0.0.1` SSH 转发端口 → 目标机 loopback 上的 noVNC/websockify → x11vnc → 独立 Xvfb 显示。VNC 不对局域网开放；不需要保存 VNC 密码，也不使用会话级 `xhost +`。远端 VNC/Web 端口自动分配，退出即关闭。渲染与图像传输有额外开销；浏览器刷新率受编码和网络影响，画面卡顿时先查看日志中的实际仿真 FPS。

其他目标机若缺少查看依赖，在目标机安装（已配置的 `.102` 无需重复）：

```bash
sudo apt-get install xvfb xauth xdotool x11vnc novnc python3-websockify
```

这只安装显示工具，ROS/OpenVINO/Vulkan 与模型等项目依赖仍按远程测试文档配置。

## 故障速查

| 现象 | 处理 |
|---|---|
| SSH 不可达 / 认证失败 | 确认 `.102` 在线；先 `ssh wuxian@192.168.1.102`；不在本机补跑仿真 |
| `Remote build missing` | 执行上方远程 `build` 命令 |
| `No accessible target desktop` | 目标机登录 X11 图形会话，或使用 `--view local` |
| `Local viewer port is busy` | 使用 `--local-port 6081` |
| 浏览器连接失败 | 使用终端打印的地址；确认命令仍在运行，查看 `viewer-vnc.log` / `viewer-web.log` |
| `Another remote job is running` | 等待前一任务结束；不要另开同目录的长期 `aim` / `sim` 作业 |
| 窗口先黑后出现 / 发弹数暂为 0 | 等待模型和场景加载；自瞄在仿真启动 5 秒后启动 |
| 到时浏览器显示已断开 | 正常结束；重新运行命令即可重新打开窗口 |

正常结束后，完整输出、退出码、自瞄诊断和仿真遥测回传到 `artifacts/remote/<作业编号>/`，终端会打印该路径。本地查看模式另回传 `viewer-vnc.log`、`viewer-web.log`。提前中断或断网时尽力回传，可能只有部分日志；不完整作业不算测试通过。
