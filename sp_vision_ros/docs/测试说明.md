## 3. 重跑与演示

在本机工作区根目录调度，不在本机直接编译或启动 Bevy：

```bash
python3 tools/remote_run.py doctor
python3 tools/remote_run.py check
# 远端缓存已有锁定的 Rust 依赖，使用离线模式避免索引网络等待
python3 tools/remote_run.py --env CARGO_NET_OFFLINE=true test
# 已构建后，单独重跑一个场景
python3 tools/remote_run.py --skip-build --scenario move --seconds 30 closed-loop
# 两端在同一作业启动，60 秒自动退出；没有 DISPLAY 时自动使用 Xvfb
python3 tools/remote_run.py --env DAEDALUS_SP_SCENARIO=static run -- \
  bash sp_vision_ros/scripts/run_pair.sh --duration-secs 60
```

需要目标机显示窗口时增加 `--env DISPLAY=:0`，并具备该桌面的 X11 访问权限。不要同时用两个长期调度作业分别启动 aim/sim，它们会等待同一个工作区锁；使用 `run_pair.sh` 或闭环脚本启动两端。目标机虚拟显示同样使用 RTX Vulkan，Xvfb 不会替代 GPU 驱动。

结果回传到 `artifacts/remote/<作业ID>/project-artifacts/`；失败也保留本次日志，旧 PASS 报告不会冒充新作业结果。环境和参数见 [SSH 测试说明](../../docs/remote-testing.md)。

## 4. 人工验收补充

以下是可继续执行的人工流程，不代表已经逐项操作：

1. F3 切到自由视角，验证外参不匹配后解除控制；返回第一人称恢复。
2. 停止算法，确认仿真指令看门狗到期删除轨迹；停止仿真，确认算法目标到期后不再控制/开火。
3. 设置 `allow_fire: false` 进行纯跟踪，然后恢复开火并检查遥测。
4. 改变分辨率/FOV 而不重新生成 YAML，应拒绝内参不一致的帧；重新生成后恢复。
5. 改变距离、遮挡、己方运动和旋转速度，进行更长时间、重复次数更多的性能测试。

## 5. 结果字段

`*_result.json` 分开记录有效规划、开火建议、实际发射、命中事件、按 ID 去重的敌方命中弹丸、已完成弹丸、尚未结束弹丸和结束停止控制。`*_diagnostics.jsonl` 保存视觉与规划，`*_metrics.jsonl` 保存物理事件；`*_last_frame.png`、两端日志用于核对视角和运行异常。
