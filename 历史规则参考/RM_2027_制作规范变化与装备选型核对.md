# 2027 制作规范变化与装备选型核对

整理日期：2026-10-15。依据本目录新加入的[2027 高校系列赛机器人制作规范 V1.0.0（20261015）](<./UTF-8__RoboMaster 2027 机甲大师高校系列赛机器人制作规范手册V1.0.0（20261015）.pdf>)（下称M27），对比[2026 制作规范 V2.0.0（20260626）](<./RoboMaster 2026 机甲大师高校系列赛机器人制作规范手册V2.0.0（20260626）.pdf>)（M26）。页码均为页脚印刷页码，两者通常对应PDF阅读器页序减1。

本文优先覆盖装备、视觉、机载计算与操作间终端。比赛运行方式、通信权限、伤害结算仍须结合对应赛事规则；2027通信协议尚未收录，不能以旧协议补齐新字段。

## 1. 对视觉、上位机影响最大的变化

| 重要程度 | 2027要求／变化 | 直接影响 | 依据 |
|---|---|---|---|
| **P0：识别目标** | 装甲受击面改为**点阵屏幕**，显示机器人编号或图案，具体样式后续更新 | 不能把旧灯条配对＋装甲贴纸数字识别当作已验证的新目标模型；需要新样本、几何标定与曝光测试 | M27 S29–S30，p.15；M26 p.19 |
| **P0：计算平台选型** | 成品模组／成品系统定义明确包含主板、CPU、GPU、内存、硬盘及笔记本等；新增计算平台价格或算力豁免路径 | 机载NUC、Jetson、独显等不能只凭“通用电脑”认定无约束，必须保存销售、用途、价格或算力证据 | M27 §2.3，p.23–25；M26 §2.3，p.30–31 |
| **P0：激光设备** | **仅允许Class I不可见激光，禁止可见激光** | 旧Class II雷达反制激光方案不适用；主动深度相机、激光雷达需核验发射类别和波段 | M27 S26–S28，p.15；M26 S25–S30，p.18 |
| **P1：相机安装** | 功能性高光泽部件与装甲的距离仍需>100mm，但测量对象由旧“装甲侧灯边缘”改为**装甲左右边缘** | 按新版装甲实体重新测距，不沿用旧灯条坐标 | M27 S36，p.16；M26 S39，p.20 |
| **P1：终端** | 收纳尺寸改为600³mm，30V最大工作电压，禁止无线收发；终端间允许有线通信 | 可重新规划终端布局与互联，但不能把有线许可扩展成Wi-Fi／蓝牙许可 | M27 表2-4、S47–S50，p.17–18；M26 表2-5、S63，p.22–23 |
| **P1：重装电气** | 模块化42mm机构最大工作电压140V、无自带电池、限制电容，并要求裁判接口电气隔离 | 30V整机与高压模块边界要明确，安装通信和供电需专门设计 | M27 S8、S70、S145，p.11、29、76 |
| **延续但重要** | 使用操作系统的机器人运算平台须用开源OS，禁止Windows／macOS | Linux、对应RTOS可以按文中示例设计；不等于自研代码必须全部公开 | M27 S60，p.20；M26 S87，p.26 |

**更正先前结论：**此前仅阅读2027比赛规则时，写了“未发现算力、操作系统的明确要求”。新加入制作规范后，该结论已不完整：现在已明确查到OS限制及计算平台豁免门槛。OS开源要求在2026已存在，不能误报为2027首次新增。

## 2. 计算机、GPU、Jetson如何判断

### 2.1 第一步：分清安装位置与用途

M27 S65及说明（p.23–24）原则上禁止第三方成品模组与成品系统，但对**雷达运算平台端、自定义终端所使用的运算平台**明确豁免，可使用成品模组和成品系统，不受这一条例限制。

因此：

- **机载自瞄／导航计算机**：不能直接套雷达／终端的特殊豁免，需继续判断市售通用产品条件。
- **雷达运算平台、操作间终端运算平台**：不受S65这项成品限制，但依然受电源、尺寸、无线、检录等其他条款约束。
- **相机、机械臂、云台、控制板等其他成品**：不得因为与计算机一起购买就整体认作“计算平台”豁免。商品组合、成品模组和成品系统如何划分，应按产品实际形态提供证据。

### 2.2 第二步：公开销售与通用用途是共同前提

M27 §2.3（p.24–25）要求产品：

1. 由合法注册企业或机构生产／销售；
2. 在**报名截止日前**已通过官网、电商、代理等渠道公开面向社会销售；
3. 主要面向通用工业、科研、教育或消费市场；
4. 不以RoboMaster或其他单一赛事为唯一／主要使用场景，不是仅赛事渠道销售的定制产品。

即使价格或算力满足要求，赛事专用产品、简单改名伪装的产品、严重替代核心技术难点的高度集成产品等，仍可能被认定禁止。

### 2.3 第三步：正确理解价格与算力逻辑

一般市售通用产品价格：

| 产品形态 | 价格条件 |
|---|---|
| 成品模组 | 单价≤5000元人民币 |
| 成品系统 | 单价≤8000元人民币 |

价格以官方标价或主流渠道含税成交价为准，组委会保留解释权。2026通用产品价格条件为单价≤5000元，2027进一步区分模组与系统。

**运算平台有专门豁免条件：满足公开销售和通用用途前提后，以下两条路径满足其一即可：**

| 路径 | 需满足的条件 |
|---|---|
| **价格路径** | 价格条件与成品系统一致，即≤8000元 |
| **峰值算力路径** | 加速算力≤160 TOPS，基准为**AI TOPS INT8稀疏值**；并核对通用算力≤25GHz，按所有处理器核心标称基准主频逐核求和 |

原文将两个算力指标并列列在“峰值算力条件”之下，本文按两项均须满足整理；复杂多芯片、CPU＋GPU组合、多个平台的计算范围需向官方确认。

可以用以下逻辑做内部预审，不能替代官方最终裁定：

```text
机载运算平台的市售通用产品豁免：
公开销售条件 AND 通用用途条件
AND [价格≤8000元 OR (AI INT8稀疏算力≤160 TOPS AND 通用算力≤25GHz)]
```

**不要误读为全部计算机都同时受8000元、160 TOPS、25GHz三个上限限制。** 价格路径和算力路径是二选一；也不要将普通成品模组5000元上限直接替代运算平台专门路径。

推算例子（仅演示规则逻辑，不对实际产品出具合规结论）：

- 通用平台售价7000元、AI算力超过160 TOPS：价格路径可能成立，不能仅因超过160 TOPS就直接判违规。
- 通用平台售价10000元、120 TOPS、8核基准2.0GHz：通用算力为16GHz，算力路径可能成立。
- 通用平台售价10000元、120 TOPS、12核基准2.5GHz：总和30GHz，不满足该算力路径，不能用“每核才2.5GHz”判断通过。
- 不得拿FP16、INT8稠密、GPU浮点TFLOPS等其他口径直接与160 TOPS门槛比较；缺厂商指定口径证据时应先核实。

原文未完整说明自行组装CPU／GPU／内存的整个平台如何定价、多处理器基准频率缺失、GPU核心是否计入通用算力等边界，不自行创造算法。

### 2.4 操作系统：不是今年新增，但此前遗漏，必须补上

M27 S60（p.20）：所有机器人上搭载的运算平台，若使用OS，须使用开源OS，例如Linux及衍生OS、RTOS，**不得使用Windows、macOS等闭源OS**。M26 S87（p.26）已有该要求，并明确列出旧控制器、客户端等设备。

2027 S60没有逐一重列合并后的自定义终端。雷达运算平台不应因S65成品豁免而自行认定同时豁免OS限制；**终端是否包含在S60“所有机器人”的OS范围内，需要结合附属设备定义向官方确认**。稳妥的当前实现选择是Linux终端，但这是工程建议，不把原文未逐项写清的范围伪装成确定结论。

OS开源与业务程序开源是不同要求：S60本身没有要求提交全部自研源码到公共平台；发生争议时展示代码、开源奖或特定评审的开源义务另按相应条文执行。

## 3. 相机与传感器：已确认的安装硬限制

### 3.1 工业相机与新装甲识别

- M27未对普通自研工业相机逐兵种给出统一的品牌、数量、焦距、分辨率或帧率上限；但相机商品仍受S65、整机重量／尺寸／供电及安装要求约束，不能简称为“相机不限”。
- S36（p.16）：镜片等无法降低光泽的部件，与装甲**左右边缘**的最短直线距离必须**>100mm**。
- S29–S30（p.15）：不得模拟视觉特征，不得改变机器人视觉特征。新装甲受击面是点阵屏幕，编号／图案样式后续更新。不得给装甲加贴纸、画额外识别标记、改显示或装饰模块（另见S119，p.61）。
- 新装甲特征意味着旧样本不构成新版已验证数据；需要测试点阵显示、曝光、运动、视角与背景干扰。不能仅凭本册断言全部旧灯条都消失：安装章节仍出现侧灯等文字，应以官方新模块实物和资料核实。

### 3.2 激光雷达、主动深度相机、补光

M27 S25–S28（p.14–15）：

- 不得安装明显的可见光／不可见光发射设备，原文对机器人状态指示灯和红外传感器有例外；不应将此扩展为任意高亮补光灯许可。
- 不得改装激光产品；安全等级按铭牌／厂家证明及检录实测，取最高标准判断。
- **所有机器人仅允许Class I不可见激光产品，禁止可见激光产品。**
- 所有光学手段不得对人员造成身体伤害。

**选型判据：**激光雷达或主动深度相机应保存激光类别、发射波长、认证资料；“Class I”与“不可见”须同时满足。红外LED与激光产品不能混为一类；屏幕及充能装置也有各自专门规则。雷达接收装置属于接收设备，不意味着可主动发射无线干扰。

机载显示屏限制为≤7寸，距显示屏40mm内照度≤300Lux，发光面距装甲≥100mm；**自定义终端被S24明确排除在该机载屏幕尺寸条款之外**，不能据此限制终端显示器只能7寸。

### 3.3 官方图传模块与定位模块

| 检查对象 | 2027要求 | 依据 |
|---|---|---|
| 图传发送端风口 | 进出风口不得遮挡；150mm内无遮挡为建议，不能将建议与强制混淆 | S147及说明，p.80 |
| 图传前方 | 模块底面中心为顶点，相机正前方保留锥角60°、无限延伸且无导电材料遮挡的指定锥体 | §3.9.2，p.80 |
| 图传天线 | 天线底面连线中心为球心，半径70mm上半球内无导电／电磁吸收材料及干扰部件 | §3.9.2，p.81 |
| 图传接口与串口 | 接口、指示灯无遮挡；UART使用3.3V TTL，采用图传链路时保护串口 | §3.9，p.79–81 |
| 图传接收端 | 附近避免金属遮挡，散热口无遮挡；比赛规则另禁取出固定支架 | S148–S149，p.82 |
| 定位模块 | 顶部朝上水平安装，上方145°无导体遮挡；刚性支架40N受力时偏移≤10° | S150–S151，p.83 |
| 定位／图传间距 | 最外沿间最短直线距离≥150mm | S152，p.83 |
| 定位模块磁环境 | 周边100mm无强磁体／导磁体／易磁化部件，不用磁体、导磁体、粘黏材料固定 | S153–S154，p.84 |
| 工业相机与测速 | 测速Logo中心**直径50mm**内不得有易磁化物质，明确含工业相机机身；直径100mm区域有针对图传与工业相机机身的例外，强磁设备仍需验证磁力角影响≤2° | S143–S144，p.75 |

**RMUL不要求安装定位模块**（M27 p.47），不能把RMUC定位模块的安装数量直接写入联盟赛BOM。

通过隧道时，测速、定位模块允许短暂遮挡；主控、图传发送端和灯条也允许短暂遮挡，但功能异常或干扰后果自负；其他模块仍须合规（M27 p.45）。这不是允许日常安装遮挡图传散热口或装甲。

### 3.4 装甲支架、姿态与相机空间

依据M27 §3.6（p.60–67）：

- 只能用官方装甲支撑架，不可修改／破坏；装甲模块不得改装装饰。
- 四块装甲分别对应机体±X、±Y，方向误差≤5°；底盘运动学和装甲安装共用规定机体坐标系。
- 模块受击面法线与−Z方向夹角75°，指定边与XY平面夹角<5°；两对装甲中心线垂直，规定方向偏移≤50mm。
- 下边缘高度≤400mm且不得触地，两块装甲下边缘高度差≤100mm；地形交互等例外按原文。
- 步兵／哨兵：受击面下边缘105°、上边缘120°、左右边缘145°内不得遮挡。
- 重装：所有装甲下边缘105°无遮挡；至少三块同时满足其他方向无遮挡，至多一块有条件遮挡，几何边界为上缘>150mm或左右边缘>170mm等原文条件。
- 禁止遮挡区域在机器人最大伸展尺寸范围内无限延伸；镜头、计算机散热器、护罩及线束都要纳入检查。

## 4. 自定义终端与无线链路

M27表2-4、S47–S50（p.17–18）：

| 项目 | 2027值／要求 |
|---|---|
| 最大工作电压 | 30V；内部任意时刻任一点相对电池负极均不得超过30V |
| 最大收纳尺寸 | 600×600×600mm；2026旧客户端为400³mm，旧控制器需另按其旧表比较 |
| 最大伸展尺寸 | 不限，但尺寸导致不便／无法参赛的后果自负；仍须适配操作间实际区域 |
| 数据传输 | 图传UDP，赛事数据MQTT＋ProtoBuf；详细通信协议待补 |
| 无线 | 不得使用无线发射／接收装置；S50没有像雷达S99那样写出“无法拆除可在OS禁用”的例外 |
| 桌面与线材 | 禁止用双面胶／螺丝等粘性或尖锐物接触操作桌面；带电线材不得直接裸露 |
| 使用前 | 接入官方数据接口测试可用 |
| UI及外观 | 终端硬件／软件／UI均不得展示赞助商品牌名称、标识、广告语等，S42 p.16 |

**终端若使用带Wi-Fi／蓝牙的笔记本，不能自动借用雷达的“软件禁用即可”条款，应先确认S50的执行要求。** 普通自带电脑禁令仍有终端例外，但“可作为终端使用”不豁免上述电压、无线和检录要求。

M27 S22（p.14）限定机载无线通信设备：除遥控器、裁判系统、雷达信息接收装置外不得搭载，另对**仅参赛机器人之间的可见光通信**给出例外；S23限制对指定频段产生干扰。

因此，不能增加Wi-Fi图传、手机热点、场外SSH控制、未经允许的射频通信。可见光通信例外还需同时满足光学与各赛项通信规则；尤其RMUL哨兵禁止多机通信，不应单凭S22就认定其允许一切视觉通信，方案需官方核实。

## 5. 雷达装备：旧数值现在已在2027确认

依据M27 S96–S104，p.41–43：

- 雷达需有传感器端与运算端，**电缆连接**，能显示调试画面。
- 运算端最大功率**750W**，其表格备注以“雷达系统使用过程中产生的总功率”描述超限切市电，预算应把系统用电纳入核查，不能只看GPU标称TDP。
- 运算端尺寸≤600×350×600mm；220V／50Hz市电条件；不得安装或使用无线设备，无法拆除时在OS禁用。
- 传感器端长宽不超平台，高度≤1500mm、最大工作电压60V；建议支架高度>1.2m，连接电缆有效长度至少5m为建议。
- 无线接收装置必须装在传感器端；传感器固定于自研支架并放置于基座，信号与供电自行解决。
- 雷达／终端**运算平台**豁免S65成品条件不代表相机、机械执行器或其他所有部件整体豁免。

750W、尺寸、软件禁用无线这些数值与旧规范对应内容基本延续；此前文档称“2027尚待确认”的部分现已可以改为已确认。

## 6. 整机与42mm模块：计算设备也占重量、包络和电量

以下只是重点摘录，不能替代各兵种完整表格。

| 步兵 | 300Wh，30V | ≤28kg含电池／裁判系统；收纳600³mm，伸展800³mm | 表2-7，p.29–30 |
| 哨兵 | 300Wh，30V | ≤28kg含电池／裁判系统；收纳600³mm，伸展800³mm | 表2-8，p.30–31 |

底盘功率限制不是整机或上位机总功率额度；但也不能把底盘动力接到Mini PC接口躲避监控。M27 S111–S115（p.56–58）明确计入底盘功率的电能不得绕过电源管理模块，发射机构断电时摩擦轮、拨弹、电磁阀等同时断电。

M27 p.45明确底盘功率定义举例：舵轮舵向电机、足式关节电机、仅攀阶／跨障的履带机构等不计入底盘功率。此处影响机械与供电设计，仍需按实际机构功能判断，不能将行走动力简单改名后排除。

模块化42mm与重装之间要满足S145（p.76）的接口电气隔离测试，检录时由队伍自行完成指定短接／误接测试。建议单独做接口保护设计评审，严格按原文测试条件操作；高压只在规定模块内，不能将整机30V上限一并提高至140V。

另有原文冲突需记录：表2-5发射机构备注写“仅能在**七分钟**比赛阶段内安装”，但RMUL是五分钟比赛；应按对应赛事专节理解并向官方确认措辞。S59一般禁止分解与比赛规则重装工作台例外也需联合阅读。

## 7. 空中系统与飞镖：不能沿用旧平台假设

### 7.1 空中机器人：小型全自动平台，视觉与计算预算显著收紧

M27 S75–S80、表2-9（p.31–34）：

- 全自动运行，配遥控器用于紧急停桨；在机库内可以与机库通信。不能把紧急停桨遥控器当作一般飞行遥控许可。
- 供电总容量≤4Wh、最大工作电压30V，不允许安装发射机构；须能持续悬停至少10秒。
- 重量上限249g，最大伸展尺寸与实测重量耦合；不能将“249g”与轻量机对应的最大尺寸随意组合。检录须自备对应尺寸的刚性敞口容器，任意伸展状态均不得超出。
- 桨叶上、下及周向均须防护，孔径<17mm；需通过17mm弹丸不可穿过和500mm高度三个方向跌落测试。
- 同一个紧急遥控器须能同时停下场上所有空中机器人；失去遥控信号也须自动停桨。
- 顶部识别灯指定**7颗XL-3528SURUBC**红蓝双色灯珠，包络圆直径≤24mm；须直流持续点亮，禁止周期性PWM或扫描驱动。灯组位置、姿态、颜色还须按S80逐项核对，自测要求后续更新。

**研发影响：**相机、运算板、电池、护桨和灯组须一起做重量／电量预算；地面NUC方案不能直接搬上空中平台。识别灯也不能用任意RGB灯带替代。

### 7.2 飞镖：明确要求定位与方向控制

M27 S86–S90（p.38）要求检录提供发射超过5m的视频；飞镖须定位检测模块，通过螺旋桨（最多1个）、舵面、喷气等方式控制方向，推重比<1。不得使用压缩空气直接推动发射飞镖；发射时触发装置须亮起，俯视不得有裁判系统与触发装置以外的外露光源。

这不是强制指定某款相机或某种视觉算法；但旧“无制导飞镖”笔记不能直接作为2027方案依据，需重新核对定位、制导、光源和触发装置。
