## 适用范围

本目录保留 2025、2026 年历史资料，并收录 2027 年高校联盟赛、超级对抗赛的比赛规则与参赛手册首次发布版。不同年份和赛事的文件应分别使用；后续设计以对应赛季、对应赛事的正式规则、修订和官方答疑为准。

规则有关的尺寸、安装位置、允许功能、通信字段和比赛参数，应在新版规则确认后再确定；保留配置和模块调整空间，不凭这些历史文件固定实现。
