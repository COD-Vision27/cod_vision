# 历史规则参考资料


## 适用范围

本目录保留 2025、2026 年历史资料，并收录 2027 年高校联盟赛、超级对抗赛的比赛规则、参赛手册及机器人制作规范首次发布版。不同年份和赛事的文件应分别使用；后续设计以对应赛季、对应赛事的正式规则、修订和官方答疑为准。

规则有关的尺寸、安装位置、允许功能、通信字段和比赛参数，应在新版规则确认后再确定；保留配置和模块调整空间，不凭这些历史文件固定实现。

## 文件分类

- 原始 PDF：比赛规则、参赛手册、机器人制作规范、通信协议、裁判系统串口协议；不同版本均保留。
- 历史整理笔记：相机位置、自瞄、无制导飞镖、雷达相关资料，共 4 份。这些笔记仅作查阅辅助，具体依据需回到对应版本的正式文件。
- 年度对比：[2027 联盟赛规则变化与重点限制](./RMUL_2027_规则变化与重点限制对比.md)，以 2026 年联盟赛比赛规则为基准，标出重大调整、延续限制及待官方确认事项。
- 新增 RMUC 2027 文件：[比赛规则](<./UTF-8__RoboMaster 2027 机甲大师超级对抗赛比赛规则手册V1.0.0（20261015）.pdf>)、[参赛手册](<./UTF-8__RoboMaster 2027 机甲大师超级对抗赛参赛手册V1.0.0（20261015）.pdf>)；二者与 RMUL 规则分开适用。
- 装备专项：[2027 装备限制、视觉与上位机要求](./RM_2027_装备限制_视觉与上位机要求.md)，汇总比赛机制对视觉、机载计算与操作间终端的影响，并同步新增制作规范的已确认限制。

- 制作规范专项：[2027制作规范变化与装备选型核对](./RM_2027_制作规范变化与装备选型核对.md)，对比2026，重点覆盖计算平台价格／算力豁免、开源OS、点阵装甲、相机安装、激光、终端、雷达与高压模块；仍待补2027通信协议。
