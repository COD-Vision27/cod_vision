# RMUC 2026 雷达规则数据

> 来源：《RoboMaster 2026 机甲大师超级对抗赛比赛规则手册 V2.2.0（2026-08-07）》

## 1. 雷达权限与数据链路

- 雷达初始区域：雷达基座。
- 运行方式：自动运行；最多配置 1 个遥控器，仅用于调试。
- 可向所有己方机器人发送数据。
- 只能接收哨兵机器人数据。
- 可向裁判系统服务器发送识别坐标、解析到的电磁波信息和反制结果。
- 雷达主控模块异常离线时：多机通信断开，激光发射装置及执行机构断电。

## 2. 雷达识别

可识别目标：双方地面机器人、空中机器人。每个目标维护独立标记进度 `P`。

| 参数 | 数值 |
|---|---:|
| `P` 初始/最小值 | 0 |
| `P` 最大值 | 150 |
| 准确坐标误差 `d` | `< 0.8 m` |
| 半准确坐标误差 `d` | `0.8 m <= d < 1.6 m` |
| 错误坐标误差 `d` | `d >= 1.6 m` |
| 数据中断判定 | 连续 `0.5 s` 未收到数据记 1 次错误 |

其中 `d` 是雷达发送坐标与机器人实际平面坐标的直线距离。

### P 更新

每次收到雷达数据，或触发数据中断时，先更新连续影响值 `x`，再更新 `P`。初始 `x = 0`。

| 当前标记状态 | `x` 更新 |
|---|---|
| 准确 | 上一次为准确/半准确：`x = x + 1.0`；否则 `x = 1.0` |
| 半准确 | 上一次为准确/半准确：`x = x + 0.5`；否则 `x = 0.5` |
| 错误 | 上一次为错误/中断：`x = x - 0.8`；否则 `x = -0.8` |
| 数据中断 | 按一次错误处理 |

```text
P = clamp(P + x, 0, 150)
```

数据中断或未被激光照射等导致的错误状态会使连续计数重置；机器人战亡后 `P` 保留，但 `x` 重置为 0。

### 敌方目标效果

| `P` 区间 | 小地图 | 地面机器人额外效果 |
|---|---|---|
| `[0,100)` | 显示雷达发送坐标 | 无 |
| `[100,120)` | 显示定位模块实际坐标并有特殊标识 | 15% 易伤 |
| `[120,150]` | 显示定位模块实际坐标并有特殊标识 | 20% 易伤 |

定位模块离线的特殊判定：

- 对方雷达对该机器人标记始终视为“准确”；
- 己方雷达对该机器人标记始终视为“错误”。

### 双倍易伤

- 雷达使敌方机器人累计处于易伤状态 1 分钟，获得 1 次机会。
- 同时使多台机器人易伤时，时间不累加。
- 消耗机会后，当前所有来源于该雷达的易伤数值翻倍，持续 30 秒。
- 每局最多触发 2 次。
- 当对方干扰波难度高于己方时，即使标记准确，也不会产生易伤或积累双倍易伤进度。

## 3. 空中机器人雷达反制

雷达可安装激光发射装置和执行机构，瞄准对方空中机器人的激光检测模块。

- 仅当对方空中机器人正在空中支援时，己方激光装置及执行机构上电。
- 被瞄准进度 `P_air` 范围：`0..100`。
- 达到对应阈值后，空中机器人发射机构锁定 45 秒，`P_air` 归零。
- 锁定期间 `P_air` 不增长。
- 每局最多成功锁定 5 次。

| 当前成功反制次数 | 下一次反制的检测难度 | 阈值 |
|---:|---|---:|
| 0（第一次前） | 难度一，检测区域正常 | 50 |
| 1-2（第二、三次前） | 难度二，检测区域纵向为原面积 `3/5` | 100 |
| 3-4（第四、五次前） | 难度三，检测区域纵向为原面积 `1/5`，且不主动发光 | 100 |

### 激光连续照射进度

判定周期固定 `0.1 s`。连续照射计数为 `n`，累计照射时间为 `t`：

```text
第 n 个 0.1 s 判定：P_air += 0.6 * n
```

- 照射中断前不足 `0.1 s`：`t`、`n` 立即归零。
- 未被照射时：`P_air` 按 `0.5/s` 衰减，不低于 0；`t`、`n` 立即归零。
- 从第四次反制成功开始，空中机器人可以支付“同等级地面机器人立即复活金币数 × 2”，解除反制并立即呼叫空中支援。

## 4. 官方电磁波解析

允许在雷达上安装天线和解调电路，解析官方广播源与干扰源。调制方式为 **2-GFSK**，映射 `0 -> -1`、`1 -> +1`。

| 波源 | 中心频点 | 带宽 | 功率 |
|---|---:|---:|---:|
| 红方广播源 | 433.20 MHz | 0.54 MHz | -60 dBm |
| 红方一级干扰源 | 432.20 MHz | 0.94 MHz | -10 dBm |
| 红方二级干扰源 | 432.50 MHz | 0.86 MHz | -10 dBm |
| 红方三级干扰源 | 432.80 MHz | 0.25 MHz | -10 dBm |
| 蓝方广播源 | 433.92 MHz | 0.54 MHz | -60 dBm |
| 蓝方一级干扰源 | 434.92 MHz | 0.94 MHz | -10 dBm |
| 蓝方二级干扰源 | 434.62 MHz | 0.86 MHz | -10 dBm |
| 蓝方三级干扰源 | 434.32 MHz | 0.25 MHz | -10 dBm |

公共参数：`SPS=47`、`BT=0.35`、`Sample Rate=1M`。各级高斯滤波 `Sensitivity`：

- 广播源：`1.5628 rad/sample`；
- 一级干扰源：`2.8194 rad/sample`；
- 二级干扰源：`2.5681 rad/sample`；
- 三级干扰源：`0.6517 rad/sample`。

```text
Symbol Rate = Sample Rate / SPS
频偏 Δf = signal_bandwidth / 2 - Sample Rate / SPS
Sensitivity = 2π × Δf / Sample Rate
```

信息波包含：对方各机器人位置、血量、剩余发弹量、持有增益、队伍剩余经济、队伍总经济、增益点占领状态。

干扰波只包含随机 6 位数字/字母密钥。开局及干扰难度变化时密钥重置。成功解析并提交密钥后，对方干扰波难度提升 1 级。

## 5. 实现检查项

```text
发送坐标频率稳定，连续 0.5 s 不得无数据
坐标平面误差 d < 0.8 m 才能稳定积累准确标记
目标丢失时立即进入错误衰减逻辑
P >= 100/120 时切换易伤状态
每局双倍易伤机会 <= 2
空中反制照射需连续满足 0.1 s 判定周期
雷达离线时停止多机通信和激光输出
仅解析官方波源，不发射干扰波、不修改裁判系统
```
